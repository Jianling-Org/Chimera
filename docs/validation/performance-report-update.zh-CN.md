## 1. 第 3.2 节：初始化成本

本次硬件重测已顺利完成并通过独立复核。在正文中需以《初始化成本重测报告.zh-CN.md》中的“测量结果”表替换旧版表格及百分比数据；注意表格统一采用毫秒（ms）单位，严禁将 6.788 毫秒误写为 6.788 秒。本次测试的三次原始测量值与范围保留在附表与补充材料中备查。

### 建议正文表述
> 初始化成本在相同的 `CPU 0–7` 绑定约束下，严格比较原生执行与基于 Chimera bootstrap 的初始化耗时。测试对每项负载先执行一对不计分的初始化预热探测，随后交替测量三对有效样本。正式测量时关闭调试日志，计时区间包含命令创建、动态链接加载与 bootstrap 完成，严格排除工件准备、静态校验及冷却时段。
> 
> 在 5 项测试工作负载中，本次 bootstrap 引入的中位耗时增量为 **24.09–38.84 毫秒**；在 3 个真实的 Linux Kbuild 内核构建任务中，耗时相对增幅仅为 **0.52%–1.65%**。全部 40 次执行均返回退出码 0，输出结果逐字节一致，未发生异常迁移与超时增量，9 项退出账本全部归零。该测量值反映的是完整命令启动阶段的初始化总开销，而非单个线程的实时迁移时延。

### 审计与保留规则
- 明确标注被测软件环境：Chimera `578ab8321`、内核 `6.18.3-chimera-d02cd7352` 及驱动 `58fd31b4c`，附带完整输入指纹与证据链身份；
- 测量仅执行三对样本，不作过度推断或新增置信区间等统计宣称；
- 历史上的 8.79/30.39 ms、94.71/127.75 ms 等旧批次数据移入历史附录，不与新中位数混算；总结章节引用的历史比例同步修正。

## 2. 第 4.1 与 4.2 节：模型自动迁移

正文中以本轮最新的 v5 协议测量结果整体替换原有的“待恢复/尚未运行”占位表述。
- **4.1（应用适配构建）**：原生运行于 X100（CPU 0–7，16 线程）；
- **4.2（标量控制构建）**：控制编译目标为 rv64gc 且全目标禁止自动 Loop/SLP 向量化，保留 GGML 手写显式 RVV，原生运行于 A100（CPU 8–15，16 线程）。

两组测试的自动迁移均从 X100 启动，配置为 `prefer-a100`，采用应用默认参数，无 `-fa off` 或侵入式诊断回调。两组分别以自身独立的原生 PPL 作为计算分母，判定容差采用用户明确授权的 **相对误差 $\le 2\%$** 原则（明确声明不作为数值差异已修复的宣称）。

### 验证证据与披露说明
- **完备的生命周期审计**：两组均完整覆盖 7 个线程梯度、10 次 16 线程重复运行以及超过 7200 秒的混合长效负载；291 轮的主线程均完成了真实跨簇物理迁移；
- **严格一致性核验**：全部 40 项 receipt、运行时 ELF、Runtime、bootstrap、Profile、注册表以及源码 4 项补丁配置均核对无误；9 项账本归零、0 超时、0 事件丢失、0 swap、0 OOM；
- **状态披露**：明确区分 50ms 离散采样 ready、初始化阶段发布与当次内核迁移资格，不作“所有线程在任意时刻均处于安全可中断状态”的过度宣称；完整披露 StackObject、1328 gate、`assume-scalar-independent`、`min_vlen_bits=256` 等前置边界条件；
- **硬件健康**：4.1 阶段内核日志连续无未知告警，健康 BKOPS 正常；4.2 阶段 3 项精准维护事件与未知告警为 0；
- **历史记录隔离**：历史测试中的 1% 越界失败、2% 空间不足失败及工作区路径异常均予以保留，不追溯篡改历史数据；两节的独立审计报告与合格凭证均通过 SHA-256 唯一指纹锁定。
